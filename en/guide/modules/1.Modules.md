# What Are Modules?
Modules are Lua programs that run inside Killscript. Regular modules run entirely on the client. The game includes around 15 such modules that make up the entire HUD, from the inventory to the chat. Built-in modules can be disabled and replaced with your own.

There are also special Reflex modules. Part of their code runs directly on the server. This allows features such as aimbots and triggerbots (automatic aiming and firing) to work without network latency, which would otherwise give a huge advantage to players with lower ping. Only one Reflex module can be running per player at a time.

Client modules run in parallel with the game, and multiple modules can also run in parallel with each other. Most of their results are applied at the start of the next frame. The exception is interfaces drawn through ImGui: they are displayed in the same frame. See the [technical notes](./5.Tech.md#client-module-execution) for details.
