# Building Your Own UI

If a module has outgrown a couple of lines through `ImGui` and needs a full interface with layout, styles, and dynamic blocks, it is more convenient to switch to UI Toolkit.

## 1. When a Module Needs Its Own GUI

If a module needs more than just printing a couple of lines through ImGui and instead requires a full interface with blocks, rows, styles, and repeating elements, UI Toolkit is the better fit.

Layout in UI Toolkit is built with UXML and USS. Conceptually, this is very similar to HTML and CSS in a web app.

To learn more about UXML, see: https://docs.unity3d.com/Manual/UIE-UXML.html

To learn more about USS, see: https://docs.unity3d.com/Manual/UIE-USS.html

<a id="2-ui-toolkit-principles"></a>
## 2. Core Principles of Working with UI Toolkit in a Module

All `.uxml` and `.uss` files must be placed in the `./ui` folder at the root of the module.

Inside them, you can use images from the module's `./images` folder by specifying a relative file path. For example, if the style file is located at `./ui/styles.uss`, then the path to `./images/icons/icon.png` inside that style file should look like this: `url("../images/icons/icon.png")`.

You can use the following template for a layout file:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements" xmlns:uie="UnityEditor.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="Root">
        
    </ui:VisualElement>
</ui:UXML>
```

Every interface object you create must have exactly one root `VisualElement`.

A UXML element can be created in one of the following ways:

- A window in an arbitrary screen position that can later be changed in UI edit mode, created through `UI:BuildFromUxml()`
- A window positioned strictly in the center that cannot be changed through UI editing, created through `UI:BuildFromUxmlAbsoluteCenter()`
- A window anchored to a specific point on the screen that cannot be changed through UI editing, created through `UI:BuildFromUxmlAbsolute()`
- An element that is not added to the screen on its own, but can later be added as a child to another element, created through `UI:CreateFromUxml()`

You can also create an empty element through `UI:CreateVisualElement()`.

## 3. Step-by-Step Interface Layout

Let's build a small module UI that shows mini statistics for teammates in the current round. During combat, the panel will display live stats for the current round, and during the buy phase it will show the results of the previous round. Rows will be sorted automatically by K/D, and their color will change from green for the best player to red for the worst.

### 3.1. Create the Module and Prepare the Structure

Create a new module through the modules menu and name it `Round KD Widget`.

The resulting structure will look like this:

```text
Round KD Widget/
├── module.json
├── localization.csv
├── scripts/
│   └── main.lua
└── ui/
    ├── RoundKdPanel.uxml
    ├── TeamKdRow.uxml
    └── styles.uss
```

### 3.2. Build the Root Panel

Now let's create the main UXML layout for the panel. It will be anchored on the left side of the screen and contain a title, a subtitle, and a container for player rows.

Open `ui/RoundKdPanel.uxml` and paste:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements" xmlns:uie="UnityEditor.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="Root" class="kd-panel">
        <ui:Label name="lblTitle" text="Round 1" class="kd-panel__title" />
        <ui:Label name="lblSubtitle" text="Current team round" class="kd-panel__subtitle" />
        <ui:VisualElement class="kd-panel__header">
            <ui:Label text="Player" class="kd-panel__header-name" />
            <ui:Label text="K" class="kd-panel__header-stat" />
            <ui:Label text="D" class="kd-panel__header-stat" />
            <ui:Label text="K/D" class="kd-panel__header-ratio" />
        </ui:VisualElement>
        <ui:VisualElement name="cntRows" class="kd-panel__rows" />
    </ui:VisualElement>
</ui:UXML>
```

The `cntRows` container is empty for now. We will add player rows into it from Lua through `UI:CreateFromUxml()` so we do not have to duplicate the layout manually.

### 3.3. Create the Row Template, Styles, and Localization

It is more convenient to move the repeated player block into a separate template. Then the module can create as many rows as the team actually needs.

Create the file `ui/TeamKdRow.uxml`:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements" xmlns:uie="UnityEditor.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="cntRow" class="kd-row" style="width: 100%; flex-direction: row;">
        <ui:VisualElement name="veAccent" class="kd-row__accent" />
        <ui:VisualElement name="veBackground" class="kd-row__background" style="flex-direction: row; width: 100%;">
            <ui:Label name="lblNickname" text="Player" class="kd-row__name" />
            <ui:Label name="lblKills" text="0" class="kd-row__stat" />
            <ui:Label name="lblDeaths" text="0" class="kd-row__stat" />
            <ui:Label name="lblRatio" text="0.0" class="kd-row__ratio" />
        </ui:VisualElement>
    </ui:VisualElement>
</ui:UXML>
```

To make the module ready for multiple languages right away, add a `localization.csv` file. In it, the first column is the string key, and the remaining columns are translations for each language.

At this stage, we already have the interface skeleton. The only remaining step is to connect it from the script and fill it with real data.

### 3.4. Connect UXML and Create Rows from the Template

First, let's create the root panel and teach the module to create player rows through `UI:CreateFromUxml()`.

At the top of `scripts/main.lua`, add:

```lua
local UiRoot = nil
local lblTitle = nil
local lblSubtitle = nil
local cntRows = nil

local RowElements = {}

local function EnsureUi()
    if UiRoot then
        return true
    end

    UiRoot = UI:BuildFromUxmlAbsolute("RoundKdPanel.uxml")
    if not UiRoot then
        return false
    end

    lblTitle = UiRoot:GetChild("lblTitle")
    lblSubtitle = UiRoot:GetChild("lblSubtitle")
    cntRows = UiRoot:GetChild("cntRows")

    return true
end

local function CreateRowElement()
    local rowRoot = UI:CreateFromUxml("TeamKdRow.uxml")
    if not rowRoot then
        return nil
    end

    cntRows:Add(rowRoot)

    return {
        root = rowRoot,
        veAccent = rowRoot:GetChild("veAccent"),
        veBackground = rowRoot:GetChild("veBackground"),
        lblNickname = rowRoot:GetChild("lblNickname"),
        lblKills = rowRoot:GetChild("lblKills"),
        lblDeaths = rowRoot:GetChild("lblDeaths"),
        lblRatio = rowRoot:GetChild("lblRatio")
    }
end
```

Two points matter here:

- `UI:BuildFromUxmlAbsolute()` immediately adds the panel to the UI root, so it always stays on the left side of the screen
- `UI:CreateFromUxml()` is convenient for repeated blocks such as table rows

### 3.5. Compute Round Stats and Color the Rows

Now let's add the full logic. It will:

- save the starting K and D values at the beginning of each round
- calculate the delta relative to the beginning of the round
- cache the previous round results when `RoundId` changes
- show the previous round during the buy phase and the current round during combat
- fetch all user-facing strings through `Localization:GetTranslation(...)`
- sort teammates by K/D and color rows from green to red

Complete `scripts/main.lua`:

```lua
local UiRoot = nil
local lblTitle = nil
local lblSubtitle = nil
local cntRows = nil

local RowElements = {}
local LastRoundId = nil
local RoundStartStats = {}
local PreviousRoundRows = nil
local PreviousRoundId = nil

local function GetAgentStats(agent)
    return agent and agent.Stats or nil
end

local function CopyScore(stats)
    return {
        Kills = stats and stats.Kills or 0,
        Deaths = stats and stats.Deaths or 0
    }
end

local function GetDisplayRatio(kills, deaths)
    if deaths <= 0 then
        return kills
    end

    return kills / deaths
end

local function FormatRatio(kills, deaths)
    return string.format("%.1f", GetDisplayRatio(kills, deaths))
end

local function GetRankColor(index, total)
    local progress = 0
    if total > 1 then
        progress = (index - 1) / (total - 1)
    end

    local r = 0.25 + (0.92 - 0.25) * progress
    local g = 0.85 + (0.34 - 0.85) * progress
    local b = 0.45 + (0.34 - 0.45) * progress

    return Color.new(r, g, b, 1.0), Color.new(r, g, b, 0.16)
end

local function EnsureUi()
    if UiRoot then
        return true
    end

    UiRoot = UI:BuildFromUxmlAbsolute("RoundKdPanel.uxml")
    if not UiRoot then
        return false
    end

    lblTitle = UiRoot:GetChild("lblTitle")
    lblSubtitle = UiRoot:GetChild("lblSubtitle")
    cntRows = UiRoot:GetChild("cntRows")

    return true
end

local function CreateRowElement()
    local rowRoot = UI:CreateFromUxml("TeamKdRow.uxml")
    if not rowRoot then
        return nil
    end

    cntRows:Add(rowRoot)

    return {
        root = rowRoot,
        veAccent = rowRoot:GetChild("veAccent"),
        veBackground = rowRoot:GetChild("veBackground"),
        lblNickname = rowRoot:GetChild("lblNickname"),
        lblKills = rowRoot:GetChild("lblKills"),
        lblDeaths = rowRoot:GetChild("lblDeaths"),
        lblRatio = rowRoot:GetChild("lblRatio")
    }
end

local function EnsureRowElements(count)
    while #RowElements < count do
        local rowElement = CreateRowElement()
        if not rowElement then
            break
        end

        table.insert(RowElements, rowElement)
    end

    for i = 1, #RowElements do
        RowElements[i].root.style.display = i <= count and DisplayStyle.Flex or DisplayStyle.None
    end
end

local function SnapshotRoundStart()
    RoundStartStats = {}

    if not DefusalGame then
        return
    end

    local agents = Agents:GetAll()
    for i = 1, agents.Length do
        local agent = agents[i]
        RoundStartStats[agent] = CopyScore(GetAgentStats(agent))
    end
end

local function BuildTeamRows(team)
    local rows = {}
    if not DefusalGame or not team then
        return rows
    end

    local agents = Agents:GetAll()
    for i = 1, agents.Length do
        local agent = agents[i]
        local stats = GetAgentStats(agent)

        if agent and agent.Team == team and stats and stats.IsConnected ~= false then
            local startStats = RoundStartStats[agent] or { Kills = 0, Deaths = 0 }
            local kills = math.max(0, (stats.Kills or 0) - (startStats.Kills or 0))
            local deaths = math.max(0, (stats.Deaths or 0) - (startStats.Deaths or 0))

            table.insert(rows, {
                Nickname = agent.Nickname,
                Kills = kills,
                Deaths = deaths,
                Ratio = GetDisplayRatio(kills, deaths),
                IsAlive = stats.IsAlive == true
            })
        end
    end

    table.sort(rows, function(a, b)
        if a.Ratio ~= b.Ratio then
            return a.Ratio > b.Ratio
        end

        if a.Kills ~= b.Kills then
            return a.Kills > b.Kills
        end

        if a.Deaths ~= b.Deaths then
            return a.Deaths < b.Deaths
        end

        return a.Nickname < b.Nickname
    end)

    return rows
end

local function CloneRows(rows)
    local result = {}

    for i = 1, #rows do
        local row = rows[i]
        result[i] = {
            Nickname = row.Nickname,
            Kills = row.Kills,
            Deaths = row.Deaths,
            Ratio = row.Ratio,
            IsAlive = true
        }
    end

    return result
end

local function HandleRoundChange(localTeam)
    if not DefusalGame then
        return
    end

    if LastRoundId == nil then
        LastRoundId = DefusalGame.RoundId
        SnapshotRoundStart()
        return
    end

    if DefusalGame.RoundId == LastRoundId then
        return
    end

    if localTeam and LastRoundId > 0 then
        PreviousRoundRows = CloneRows(BuildTeamRows(localTeam))
        PreviousRoundId = LastRoundId
    end

    LastRoundId = DefusalGame.RoundId
    SnapshotRoundStart()
end

local function DrawRows(rows)
    EnsureRowElements(#rows)

    for i = 1, #rows do
        local row = rows[i]
        local refs = RowElements[i]
        local accentColor, backgroundColor = GetRankColor(i, #rows)

        refs.veAccent.style.backgroundColor = accentColor
        refs.veBackground.style.backgroundColor = backgroundColor
        refs.lblKills.style.color = accentColor
        refs.lblRatio.style.color = accentColor
        refs.root.style.opacity = row.IsAlive and 1.0 or 0.55

        refs.lblNickname.text = row.Nickname
        refs.lblKills.text = tostring(row.Kills)
        refs.lblDeaths.text = tostring(row.Deaths)
        refs.lblRatio.text = FormatRatio(row.Kills, row.Deaths)
    end
end

local function Tick()
    if not EnsureUi() then
        return
    end

    if not DefusalGame or DefusalGame.IsGameEnded then
        UiRoot.visible = false
        return
    end

    local localAgent = Agents:GetLocalAgent()
    if not localAgent then
        UiRoot.visible = false
        return
    end

    UiRoot.visible = true

    local localTeam = localAgent.Team
    HandleRoundChange(localTeam)

    local rows = nil
    if DefusalGame.Stage == EDefusalRoundStage.Buy and PreviousRoundRows and #PreviousRoundRows > 0 then
        lblTitle.text = Localization:GetTranslation("RoundResults") .. " " .. tostring(PreviousRoundId)
        lblSubtitle.text = Localization:GetTranslation("PreviousRoundDuringBuy")
        rows = PreviousRoundRows
    else
        if DefusalGame.RoundId <= 0 then
            lblTitle.text = Localization:GetTranslation("Warmup")
        else
            lblTitle.text = Localization:GetTranslation("Round") .. " " .. tostring(DefusalGame.RoundId)
        end

        lblSubtitle.text = Localization:GetTranslation("CurrentTeamRound")
        rows = BuildTeamRows(localTeam)
    end

    DrawRows(rows)
end

Scheduler:OnFrame(Tick)
```

The idea here is straightforward:

- in `UXML`, static labels such as `Player` or `K/D` are better defined through `LocalizedLabel`
- in `Lua`, dynamic strings such as `Round 5` or `Round results 4` are more convenient to build through `Localization:GetTranslation(...)`

At this point, the basic interface is ready. We now have a compact HUD block on the left that does not require manual row duplication and clearly shows how to combine `BuildFromUxmlAbsolute()`, `CreateFromUxml()`, and live data updates from Lua.
