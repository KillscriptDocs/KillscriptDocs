## What an Interface Consists Of

UXML describes the element tree: panels, labels, buttons, and input fields. USS controls their appearance and layout. Lua connects the interface to the game by updating data and handling player actions.

If you are familiar with HTML and CSS, the principles will feel similar. The elements and styles available to modules are listed in chapters two and three.

## Files and UI Creation

All `.uxml` and `.uss` files must be placed in the `./ui` folder at the module root.

Inside them, you can use images from the module's `./images` folder by specifying a relative file path. For example, if the style file is located at `./ui/styles.uss`, the path to `./images/icons/icon.png` in that style file should be `url("../images/icons/icon.png")`.

You can use the following layout template:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="Root">

    </ui:VisualElement>
</ui:UXML>
```

Every interface object you create must have exactly one root `VisualElement`.

A UXML element can be created in one of the following ways:

- A window in an arbitrary screen position that can later be changed in UI edit mode is created with `UI:BuildFromUxml()`
- A window positioned strictly in the center that cannot be changed through UI editing is created with `UI:BuildFromUxmlAbsoluteCenter()`
- A window anchored to a specific point on the screen that cannot be changed through UI editing is created with `UI:BuildFromUxmlAbsolute()`
- An element that is not added to the screen on its own, but can later be added as a child of another element, is created with `UI:CreateFromUxml()`
- An interface that handles mouse input, such as a menu with buttons, is created with `UI:BuildFromUxmlInteractive()`. Use `UI:OpenWindow()` to open a window with the cursor.

You can also create an empty element with `UI:CreateVisualElement()`.
