## 1. Important Details

For the aimbot, we will use a module with the `IsReflex` flag. This is a special type of module that differs from a regular one.

Such modules have two important characteristics. First, only one module with the `Reflex` tag can be enabled at the same time. Second, it has a server file at `scripts/server.lua`.

For more details, see: [Tech.md / Reflex flag](./5.Tech.md#reflex-flag)

Running aim logic on the server is useful because in firefights it reduces the advantage of players with low ping. In addition, the server-side code can access predicted shot trajectories and use them to estimate the probability of a hit through `FirearmItem:GetPredictedHits()` ([Item.md](../../api/Item.md#getpredictedhits)).

When a player joins a map, the game takes the code from `scripts/server.lua` and sends it to the server.

The server-side part cannot send arbitrary data to the client outside the module API. Console output through `print()` is also available for server-side debugging.

The client and server parts of a Reflex module can exchange Lua tables through [`Network`](../../api/Network.md#network). Use `Network:SendTable(table)` to send a table and register a callback through `Network:OnTableReceived(callback)` to handle incoming data.

The following types are supported in sent tables:

- `string`
- `number`
- `boolean`
- `nil`
- nested tables

Both sides use the same methods: the client can send a table to the server, and the server can send one to the client. Values of unsupported types are silently ignored when sent.

## 2. What Exactly We Are Going to Build

We will build a simple aimbot that tries to aim for the head with an 80% chance when using sniper weapons and the revolver.

For all other weapons, it will try to hit both the head and the body with a 50% chance.

## 3. Step-by-Step Implementation

### 3.1. Create the Module

![](../../../images/reflex_create.png)

Create a new module through the modules menu, and make sure to enable the `Is Reflex` option when creating it.

### 3.2. Simple Head Aim and Shooting

First, let's build the most basic server-side part. It will:

- look for the visible target closest to the crosshair
- get that target's head hitbox
- aim at the center of that hitbox
- hold down the fire button

Open `scripts/server.lua` and paste:

```lua
---@type Agent | nil
local LocalAgent = nil

local HALF_FOV_COS = math.cos(12 * math.pi / 180)

local function IsAgentAlive(agent)
    return agent and agent.Health and agent.Health.IsAlive == true
end

local function GetAimDot(target, firePos)
    local toTarget = (target.Aim.Position - firePos).normalized
    return Vector3.Dot(LocalAgent.Aim.Direction, toTarget)
end

local function FindHitboxByBodyPart(target, bodyPart)
    local hitboxes = target:GetHitboxes()

    for i = 0, hitboxes.Length - 1 do
        local hitbox = hitboxes[i]
        if hitbox and hitbox.BodyPart == bodyPart then
            return hitbox
        end
    end

    return nil
end

local function FindBestTarget(firePos)
    local enemies = Agents:GetEnemies()
    local bestTarget = nil
    local bestDot = HALF_FOV_COS

    for i = 0, enemies.Length - 1 do
        local enemy = enemies[i]
        if IsAgentAlive(enemy) and enemy.IsVisible then
            local dot = GetAimDot(enemy, firePos)
            if dot > bestDot then
                bestDot = dot
                bestTarget = enemy
            end
        end
    end

    return bestTarget
end

local function Tick()
    LocalAgent = Agents:GetLocalAgent()
    if not IsAgentAlive(LocalAgent) then
        return
    end

    local currentItem = LocalAgent.Inventory.CurrentItem
    if not currentItem or not currentItem.IsFirearm then
        LocalAgent.Aim:ResetAimTarget()
        return
    end

    local firearm = currentItem.AsFirearmItem
    local firePos = LocalAgent.Aim.Position
    local target = FindBestTarget(firePos)

    if not target then
        LocalAgent.Aim:ResetAimTarget()
        return
    end

    local headHitbox = FindHitboxByBodyPart(target, EHitboxBodyPart.Head)
    if not headHitbox then
        LocalAgent.Aim:ResetAimTarget()
        return
    end

    LocalAgent.Aim:SetAimTarget(headHitbox.Position, target)

    if firearm.HasAmmo and not firearm.IsReloading then
        AgentInput:SetButtonState(EInputButton.Fire, true)
    end
end

Events:On("Tick", Tick)
```

This version is intentionally very simple. We are not adding advanced accuracy checks yet; we are just building a clear foundation: if we found an enemy and a head hitbox, we aim and shoot.

### 3.3. Weapon-Based Mode Selection and Sending `SniperMode`

> TODO: Update the example below to use `Network:SendTable()` and `Network:OnTableReceived()` instead of the removed `Network` table and `NetworkProvider:SendBuffer()`.

Now let's split weapons into two modes:

- `SniperMode = true` for `SniperRifle` and `Revolver`, so the module aims for the head
- `SniperMode = false` for everything else, so the module aims for the body

To do this, add a client file at `scripts/main.lua`. It will detect the current weapon mode and send it to the server:

```lua
-- TODO: Update the example to use Network:SendTable() and Network:OnTableReceived().
---@type FirearmItem | nil
local CurrentFirearm = nil

local function IsAgentAlive(agent)
    return agent and agent.Health and agent.Health.IsAlive == true
end

local function GetWeaponName(firearm)
    return string.gsub(firearm.Name, " ", "")
end

local function GetDefaultSniperMode(weaponName)
    return weaponName == "SniperRifle" or weaponName == "Revolver"
end

local function LoadSniperModeForWeapon()
    if not CurrentFirearm then
        return
    end

    local weaponName = GetWeaponName(CurrentFirearm)
    Network.SniperMode = GetDefaultSniperMode(weaponName)
    NetworkProvider:SendBuffer()
end

local function CheckFirearmChanged()
    local localAgent = Agents:GetLocalAgent()
    if not localAgent then
        CurrentFirearm = nil
        return false
    end

    local currentItem = localAgent.Inventory.CurrentItem

    if currentItem and currentItem.IsFirearm then
        local firearm = currentItem.AsFirearmItem

        if not CurrentFirearm or firearm.Name ~= CurrentFirearm.Name then
            CurrentFirearm = firearm
            return true
        end
    else
        if CurrentFirearm then
            CurrentFirearm = nil
            return true
        end
    end

    return false
end

local function Tick()
    local localAgent = Agents:GetLocalAgent()
    if not IsAgentAlive(localAgent) then
        return
    end

    if CheckFirearmChanged() and CurrentFirearm then
        LoadSniperModeForWeapon()
    end
end

Network.SniperMode = false
Events:On("Tick", Tick)
```

Then update `scripts/server.lua` so it no longer looks only at the head. When `SniperMode = true`, it aims for the head. Otherwise, it aims for the body:

```lua
local function GetAimHitbox(target)
    if Network.SniperMode then
        return FindHitboxByBodyPart(target, EHitboxBodyPart.Head)
    end

    return FindHitboxByBodyPart(target, EHitboxBodyPart.Body)
        or FindHitboxByBodyPart(target, EHitboxBodyPart.Head)
end
```

And inside the `Tick` handler, replace the head hitbox lookup with:

```lua
local hitbox = GetAimHitbox(target)
if not hitbox then
    LocalAgent.Aim:ResetAimTarget()
    return
end

LocalAgent.Aim:SetAimTarget(hitbox.Position, target)
```

Now the firing mode is determined automatically by the weapon, and the server reads this value from `Network`.

### 3.4. Manual Mode Switching and Saving Through `Storage`

Automatic selection is convenient as a default value, but it is better to give the player a way to change the mode manually.

First, create an `inputs.json` file to bind a toggle key:

```json
{
  "Actions": [
    {
      "Name": "ToggleSniperMode",
      "Type": "Button",
      "Binding": {
        "Path": "<Keyboard>/v"
      }
    }
  ]
}
```

Now update `scripts/main.lua`. The logic will be:

- when the weapon changes, try to load the saved value from `Storage`
- if there is no saved value, use the default mode from step 3
- when the key is pressed, toggle the mode, save it, and send it to the server again

```lua
---@type FirearmItem | nil
local CurrentFirearm = nil

local ToggleSniperModeAction = nil

local function IsAgentAlive(agent)
    return agent and agent.Health and agent.Health.IsAlive == true
end

local function GetWeaponName(firearm)
    return string.gsub(firearm.Name, " ", "")
end

local function GetDefaultSniperMode(weaponName)
    return weaponName == "SniperRifle" or weaponName == "Revolver"
end

local function SaveSniperModeForWeapon()
    if not CurrentFirearm then
        return
    end

    if not Storage.Weapons then
        Storage.Weapons = {}
    end

    local weaponName = GetWeaponName(CurrentFirearm)
    Storage.Weapons[weaponName] = {
        SniperMode = Network.SniperMode
    }

    StorageProvider:SaveStorageTable()
end

local function LoadSniperModeForWeapon()
    if not CurrentFirearm then
        return
    end

    local weaponName = GetWeaponName(CurrentFirearm)

    if Storage.Weapons
        and Storage.Weapons[weaponName]
        and Storage.Weapons[weaponName].SniperMode ~= nil then
        Network.SniperMode = Storage.Weapons[weaponName].SniperMode
    else
        Network.SniperMode = GetDefaultSniperMode(weaponName)
    end

    NetworkProvider:SendBuffer()
end

local function ToggleSniperMode()
    if not CurrentFirearm then
        return
    end

    Network.SniperMode = not Network.SniperMode
    SaveSniperModeForWeapon()
    NetworkProvider:SendBuffer()
end

local function CheckFirearmChanged()
    local localAgent = Agents:GetLocalAgent()
    if not localAgent then
        CurrentFirearm = nil
        return false
    end

    local currentItem = localAgent.Inventory.CurrentItem

    if currentItem and currentItem.IsFirearm then
        local firearm = currentItem.AsFirearmItem

        if not CurrentFirearm or firearm.Name ~= CurrentFirearm.Name then
            CurrentFirearm = firearm
            return true
        end
    else
        if CurrentFirearm then
            CurrentFirearm = nil
            return true
        end
    end

    return false
end

local function Tick()
    local localAgent = Agents:GetLocalAgent()
    if not IsAgentAlive(localAgent) then
        return
    end

    if CheckFirearmChanged() and CurrentFirearm then
        LoadSniperModeForWeapon()
    end
end

Network.SniperMode = false

StorageProvider:LoadStorageTable()

ToggleSniperModeAction = InputActions:FindAction("ToggleSniperMode")
ToggleSniperModeAction:OnPerformed(ToggleSniperMode)
Events:On("Tick", Tick)
```

In essence, this repeats the same idea as in `Default Reflex+`: save settings separately for each weapon, then restore them again when the player switches weapons.

### 3.5. Simple Current Mode Display Through `ImGui`

The last thing to do is show the player which mode is currently active. We will not build any windows; we will simply draw text at the bottom of the screen.

Add this function to `scripts/main.lua`:

```lua
local function DrawSniperMode()
    if not CurrentFirearm then
        return
    end

    local text = "Sniper: off"
    if Network.SniperMode then
        text = "Sniper: on"
    end

    ImGui:DrawText(
        text,
        Rect((Screen.Width * 0.5) - 100, Screen.Height - 80, 200, 30),
        20,
        Color(1.0, 1.0, 1.0, 1.0),
        TextAnchor.MiddleCenter)
end
```

And call it inside the `Tick` handler after updating the mode:

```lua
local function Tick()
    local localAgent = Agents:GetLocalAgent()
    if not IsAgentAlive(localAgent) then
        return
    end

    if CheckFirearmChanged() and CurrentFirearm then
        LoadSniperModeForWeapon()
    end

    DrawSniperMode()
end

Events:On("Tick", Tick)
```
