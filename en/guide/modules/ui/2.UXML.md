# UXML Support in Modules

[Creating Interfaces](../3.UI.md) · Chapter 2 of 4 · [Previous: Your First Interface](./1.QuickStart.md) · [Next: USS Styling](./3.USS.md)

UXML defines which elements appear in your interface and how they are nested. This chapter lists the tags and attributes available to modules and shows how to use them.

## Document Structure

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="Root">
        <ui:Label text="Hello!" />
    </ui:VisualElement>
</ui:UXML>
```

Place `.uxml` and `.uss` files in the module's `ui` folder. Use one root `VisualElement`. The `xmlns:ui="UnityEngine.UIElements"` declaration lets you write standard elements with the `ui:` prefix; copy it from the example.

| Construct | Support and use |
|---|---|
| `ui:UXML` | Document wrapper. |
| `Style`, `ui:Style` | Connects USS through `src`; USS text inside the tag is also read. A separate file is more convenient for examples. |
| `ui:Template` | Declares a template: `name` assigns an alias and `src` specifies the UXML file. Declare it before use. |
| `ui:Instance` | `template` selects a declared template. An extra `VisualElement` is created as a wrapper around the template root; common attributes are applied to the wrapper. |
| `AttributeOverrides`, data bindings, arbitrary tags | Not supported. Use elements from the table below and define data and behavior through Lua. |

Example using a single-root `ui/Row.uxml` file:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <ui:Template name="Row" src="Row.uxml" />
    <ui:VisualElement name="Root">
        <ui:Instance template="Row" name="FirstRow" />
        <ui:Instance template="Row" name="SecondRow" />
    </ui:VisualElement>
</ui:UXML>
```

Template files are looked up by filename, so do not rely on distinguishing two files named `Row.uxml` in different subfolders. Do not create cyclic template references. For a dynamic list, use `UI:CreateFromUxml("Row.uxml")` and `container:Add(row)`.

## Common Attributes

These attributes are available on every element in the next table. Spell attribute names exactly as shown; an unknown attribute may be ignored without an error message.

| Attribute | Value / initial value | Purpose |
|---|---|---|
| `name` | String; `""` | Lookup through `GetChild("Name")` and the `#Name` selector. |
| `class` | Space-separated names | For example, `class="panel compact"` matches `.panel` and `.compact`. |
| `style` | USS declarations | For example, `style="width: 100%; height: 40px;"`. |
| `enabled` | `true` / `false`; `true` | Whether the element is enabled. This does not control visibility. |
| `picking-mode` | `Position` / `Ignore`; `Position` | Whether the element itself participates in mouse target picking. `Ignore` does not automatically disable all descendants. UI creation methods may override the root's mode. |
| `focusable` | `true` / `false`; `true` | Whether the element can receive focus. |
| `tabindex` | Integer; `0` | Focus navigation index. The exact spelling is `tabindex`, without a hyphen. |
| `tooltip` | String; `""` | Passed to the element's tooltip property; whether it is shown depends on the game's UI. |
| `view-data-key` | String; `""` | Internal element-state key. Use `Config` or `Storage` to save module settings. |
| `usage-hints` | `None` by default | Internal setting; leave the default for a regular interface. |
| `language-direction` | `Inherit`, `LTR`, `RTL`; `Inherit` | Text direction. |

## Elements and Additional Attributes

The **Children** column indicates whether other UXML tags can be nested inside an element. When it says **No**, nested markup is ignored; configure the element with attributes and Lua instead. For grouping and laying out elements, primarily use `VisualElement`, `ScrollView`, `Foldout`, and `GroupBox`.

In the table, **text attributes** means `text` (a string, empty by default), plus `enable-rich-text` and `parse-escape-sequences` (booleans, `false` by default). Text between tags does not replace the `text` attribute. Rich text inside an XML attribute must be escaped, for example `text="&lt;b&gt;Important&lt;/b&gt;"`.

| Tag | Purpose and additional attributes | Children | Lua type |
|---|---|:---:|---|
| `ui:VisualElement` | Container; common attributes only | Yes | `VisualElement` |
| `ui:TextElement` | Text attributes | Yes | `TextElement` |
| `ui:Label` | Label; text attributes | Yes | `LabelElement` |
| `ui:GroupBox` | Group with a `text` title | Yes | `VisualElement` |
| `ui:Button` | Text attributes; `click-sound-event`, `additional-click-sound-event` (strings), `disable-click-sound` (boolean) | Yes | `ButtonElement` |
| `ui:Toggle` | `label` (string), `value` (boolean) | No | `ToggleElement` |
| `ui:Scroller` | `low-value`, `high-value`, `value` (numbers), `direction` | No | `ScrollerElement` |
| `ui:ScrollView` | `mode`; `horizontal-scroller-visibility`, `vertical-scroller-visibility`; boolean `show-horizontal` / `show-horizontal-scroller`, `show-vertical` / `show-vertical-scroller` | Yes | `ScrollViewElement` |
| `ui:Foldout` | Expandable group: `text` (string), `value` (boolean) | Yes | `FoldoutElement` |
| `ui:Slider` | `label`; `low-value`, `high-value`, `value`, `page-size` (numbers); `direction`; `show-input-field`, `inverted` (booleans) | No | `SliderElement` |
| `ui:SliderInt` | Same as `Slider`, but bounds and value are integers | No | `SliderIntElement` |
| `ui:MinMaxSlider` | `label`; `min-value`, `max-value`, `low-limit`, `high-limit` (numbers) | No | `MinMaxSliderElement` |
| `ui:DropdownField` | `label`; `value` contains comma-separated choices; `index` is the zero-based selected index, `-1` by default | No | `DropdownFieldElement` |
| `ui:Dropdown` | Alias for `DropdownField` with the same attributes; prefer the primary name `ui:DropdownField` | No | `DropdownFieldElement` |
| `ui:RadioButton` | `label` (string), `value` (boolean) | No | `RadioButtonElement` |
| `ui:RadioButtonGroup` | `label`; `choices` contains comma-separated choices; `value` is a zero-based index, `-1` by default | No | `VisualElement` |
| `ui:ProgressBar` | `title`; `low-value`, `high-value`, `value` (numbers; defaults are `0`, `100`, `0`) | No | `ProgressBarElement` |
| `ui:Image` | Common attributes only; `src`, `image`, and `sprite` are not read | Yes | `ImageElement` |
| `ui:IntegerField` | `label` (string), `value` (integer) | No | `IntegerFieldElement` |
| `ui:FloatField` | `label` (string), `value` (number) | No | `FloatFieldElement` |
| `ui:TextField` | `label`, `value` (strings), `max-length` (integer), `multiline`, `is-read-only` (booleans) | No | `TextFieldElement` |
| `ColorField` | Color picker: `value`, `default-value` (colors), `show-reset-button` (boolean) | No | `ColorFieldElement` |
| `LocalizedLabel` | `text`, `localization-key` (strings), `enable-rich-text`, `parse-escape-sequences` (booleans) | Yes | `LocalizedLabelElement` |
| `KeyTip` | Key hint: `action-path`, `prefix`, `suffix` (strings), `force-text-mode` (boolean) | Yes | `KeyTipElement` |
| `Painter` | Drawing from Lua: `line-cap`, `line-join` | Yes | `PainterElement` |

Write `ColorField`, `LocalizedLabel`, `KeyTip`, and `Painter` without the `ui:` prefix. From Lua, `GroupBox` and `RadioButtonGroup` expose only the common `VisualElement` properties and methods; there are no specialized group-control properties.

For `direction`, use `Horizontal` or `Vertical`. For `ScrollView.mode`, use `Vertical`, `Horizontal`, or `VerticalAndHorizontal`. For scrollbar visibility, use `Auto`, `AlwaysVisible`, or `Hidden`. Do not combine the old boolean scrollbar attributes with the new visibility attributes.

By default, both scrollbars on `ScrollView` are hidden. To display the vertical scrollbar when needed, set `vertical-scroller-visibility="Auto"`. Define dropdown choices with the `value` attribute, not nested elements.

The initial bounds of `Slider`, `SliderInt`, and `Scroller` are zero, so set their ranges explicitly. See the [UI API](../../../api/UI.md) for available Lua properties.

Example with a choice and a numeric value:

```xml
<ui:DropdownField name="Mode" label="Mode" value="Normal,Compact" index="0" />
<ui:Slider name="Size" label="Size" low-value="10" high-value="100" value="40" />
```

This fragment belongs inside the root element. Commas separate choices and surrounding whitespace is trimmed; this format does not escape a comma inside a single choice.

For an image, use `background-image` from [USS](./3.USS.md#images) or the `ImageElement` methods from Lua. For example, assign the `icon` class to a container and use `.icon { width: 32px; height: 32px; background-image: url("../images/icon.png"); }`.
