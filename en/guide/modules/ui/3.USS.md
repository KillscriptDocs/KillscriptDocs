# USS Support in Modules

[Creating Interfaces](../3.UI.md) · Chapter 3 of 4 · [Previous: UXML Layout](./2.UXML.md) · [Next: Round Statistics Panel](./4.RoundStats.md)

USS controls the appearance of UXML elements: size, layout, colors, text, and images. This chapter collects the available properties, example values, and limitations to consider when building a module interface.

## Connecting Styles

Create `ui/styles.uss` and connect it before the root element:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="Root" class="panel">
        <ui:Label name="Title" text="Settings" />
    </ui:VisualElement>
</ui:UXML>
```

```css
.panel {
    width: 300px;
    padding: 12px;
    background-color: rgb(20, 26, 36);
}

#Title {
    color: rgb(255, 255, 255);
    font-size: 18px;
}
```

For a USS file in a subfolder, use a path relative to `ui`, such as `src="themes/dark.uss"`, even if the UXML file itself is in another subfolder. You may include `./` at the beginning of the path.

## Selectors, States, and Variables

| Syntax | Support / example |
|---|---|
| `*` | All elements. |
| `Label` | Type name without `ui:`. A custom element's type name may differ from its short UXML tag, so classes are more convenient. |
| `.panel`, `#Title` | An element's class and `name`. |
| `.panel.compact`, `Label.title` | A combination of conditions on one element. |
| `.panel Label` | A descendant at any depth. |
| `.panel > Label` | A direct child. |
| `.title + .subtitle`, `.title ~ .row` | The next sibling / subsequent siblings with the same parent. |
| `.title, .subtitle` | Multiple selectors for one rule. |
| `:first-child`, `:last-child` | The parent's first / last child. |
| `:enabled`, `:disabled` | The element's own enabled state. Disabling the parent alone does not switch this selector on a child. |
| `:hover` | Mouse hover state. Start with a simple `.button:hover`; to handle the pointer leaving, specify the regular value of the same property in `.button`. |
| `:root` | Use it to declare shared variables. A panel's class is more convenient for styling that specific panel. |
| `:focus`, `:active`, `:checked`, `:nth-child(...)`, `:not(...)`, attribute selectors | Not supported. Use classes and Lua for state. |

If several rules change the same property, prefer simple selectors: the `#Title` name has priority over the `.title` class, and a class has priority over the `Label` type. A style in UXML's `style` attribute is applied after regular USS rules. For complex combinations, do not expect exact browser CSS behavior; do not use `!important`.

Declare variables in a separate `:root` block:

```css
:root {
    --panel-color: #141A24;
    --panel-padding: 12px;
}

.panel {
    background-color: var(--panel-color);
    padding: var(--panel-padding);
}
```

Explicitly declare used variables in `:root`; they are shared by the style sheets connected to this interface. Declaring a variable inside `.panel` does not create a separate value for that panel. A fallback in `var(--name, #FFFFFF)` does not replace variable declarations: if no variables are declared at all, it may not work. Avoid nested functions in fallback values.

`@import`, `@media`, and `@keyframes` are not supported. Connect multiple USS files with separate `Style` elements. Create animations with the transitions described below or with `ScheduleAnimation` in Lua.

## Value Formats

| Format | How to use it |
|---|---|
| Length | `12px`, `50%`, `0`; a number without a unit is treated as a pixel length. `%` is meaningful only for properties that support relative dimensions. |
| Length keywords | `auto` and `none`; applicability depends on the property. For example, `width: auto`, `max-width: none`. |
| Number | `0.5`, `1`, `24`; use a period as the decimal separator. |
| Color | `#RRGGBB`, `#RRGGBBAA`, `rgb(20, 40, 60)`, `rgba(20, 40, 60, 0.5)`. RGB channels range from 0 to 255; alpha ranges from 0 to 1. |
| Boolean UXML values | `true` / `false`; these do not replace USS values such as `display: none`. |

The `em`, `rem`, `vw`, and `vh` units and `calc(...)` expressions are not implemented as their corresponding CSS values. An unknown unit may be read as pixels and an invalid value as zero, so the absence of an error does not prove support.

## Layout Properties

Properties are grouped by purpose. The right column lists valid values and examples. Some familiar properties are not yet available in the game; these are called out separately.

| Properties | Values / use |
|---|---|
| `width`, `height`, `min-width`, `min-height`, `max-width`, `max-height` | Lengths, for example `width: 100%`, `min-height: 32px`. |
| `position` | `relative`, `absolute`. |
| `left`, `right`, `top`, `bottom` | Lengths; for example `right: 20px; bottom: 20px`. |
| `display` | `flex`, `none`; `none` removes the element from layout. |
| `flex-direction` | `row`, `column`, `row-reverse`, `column-reverse`. |
| `flex-wrap` | `nowrap`, `wrap`, `wrap-reverse`. |
| `flex-grow`, `flex-shrink` | Numeric factors, for example `flex-grow: 1`. |
| `flex-basis` | Initial size along the main axis: a length or `auto`. |
| `flex` | `none`, `auto`, `initial`, or grow, shrink, and size: `1 1 0%`. |
| `align-content`, `align-items`, `align-self` | Cross-axis alignment, such as `flex-start`, `center`, `flex-end`, `stretch`. Use `auto` for `align-self` to follow the parent's alignment. |
| `justify-content` | `flex-start`, `center`, `flex-end`, `space-between`, `space-around`, `space-evenly`. |
| `margin`, `margin-top`, `margin-right`, `margin-bottom`, `margin-left` | Outer spacing; the shorthand accepts 1–4 space-separated lengths. |
| `padding`, `padding-top`, `padding-right`, `padding-bottom`, `padding-left` | Inner spacing; the shorthand accepts 1–4 space-separated lengths. |
| `aspect-ratio` | A positive number, a ratio such as `16 / 9`, or `auto`. |
| `overflow` | `visible`, `hidden`. |
| `-unity-overflow-clip-box` | `padding-box`, `content-box`. |

For four spacing values, the order is top, right, bottom, left. For two values, it is vertical and horizontal. Example: `padding: 8px 12px`.

Example row with a growing name and a fixed-size counter:

```css
.row {
    flex-direction: row;
    align-items: center;
    height: 32px;
}

.row-name {
    width: 0;
    flex-grow: 1;
    overflow: hidden;
    white-space: nowrap;
    text-overflow: ellipsis;
}

.row-count {
    width: 48px;
    margin-left: 8px;
}
```

## Backgrounds, Borders, and Images

| Properties | Values / use |
|---|---|
| `background-color` | Color. |
| `background-image` | `none` or `url("../images/icon.png")`; always put the path in quotes inside `url`. |
| `background-position` | For example, `center center`, `left top`, `right 8px bottom 8px`. |
| `background-position-x`, `background-position-y` | Axis position: `center`, `left 8px` for X, `top 8px` for Y; a length is also accepted. |
| `background-size` | `cover`, `contain`, `auto`, one or two lengths. One length sets both axes: `32px` means `32px 32px`. |
| `background-repeat` | `repeat`, `no-repeat`, `round`, `space`, `repeat-x`, `repeat-y`; two axis-specific values can be given. |
| `-unity-background-image-tint-color` | Image color multiplier. |
| `-unity-background-scale-mode` | `stretch-to-fill`, `scale-and-crop`, `scale-to-fit`. |
| `border-color`, `border-top-color`, `border-right-color`, `border-bottom-color`, `border-left-color` | Side colors. In the `border-color` shorthand, use space-free hex values: `#FFFFFF #808080`. |
| `border-width`, `border-top-width`, `border-right-width`, `border-bottom-width`, `border-left-width` | Thickness in pixels. The shorthand accepts 1–4 values. |
| `border-radius`, `border-top-left-radius`, `border-top-right-radius`, `border-bottom-right-radius`, `border-bottom-left-radius` | Radii. Shorthand order: top-left, top-right, bottom-right, bottom-left. The `/` syntax is not implemented. |
| `-unity-slice-left`, `-unity-slice-top`, `-unity-slice-right`, `-unity-slice-bottom` | Integer edge sizes for a nine-slice image, for example `4`. |
| `-unity-slice-scale` | Numeric edge scale. |
| `-unity-slice-type` | Nine-slice image fill method, for example `sliced`. |
| `opacity` | A number from `0` to `1`; zero opacity does not remove the element from layout. |
| `filter` | Implemented filters: `blur`, `contrast`, `grayscale`, `hue-rotate`, `invert`, `opacity`, `sepia`, `tint`; for example `blur(2px)` or `tint(#FFFFFF)`. `none` clears the list. |

Border and spacing shorthands are split on spaces, so `border-color: rgb(20, 40, 60)` is not a reliable shorthand format. Use `border-color: #14283C` or separate side properties with `rgb(...)`.

### Adding an Image

Place `icon.png` in the module root's `images` folder. `.png`, `.jpg`, and `.jpeg` are supported; SVG is not.

```css
.icon {
    width: 32px;
    height: 32px;
    background-image: url("../images/icon.png");
    background-size: contain;
    background-repeat: no-repeat;
}
```

In UXML, `<ui:VisualElement class="icon" />` is enough. Specify an image from the module folder; internet image URLs are not supported. For a nested image, use a path such as `../images/icons/icon.png`.

## Text

| Properties | Values / use |
|---|---|
| `color` | Text color. |
| `font-size` | Size, for example `16px`. |
| `letter-spacing`, `word-spacing`, `-unity-paragraph-spacing` | Lengths: spacing between letters, words, and paragraphs. |
| `white-space` | `normal`, `nowrap`. |
| `text-overflow` | `clip`, `ellipsis`; for an ellipsis, also constrain the width and set `overflow: hidden; white-space: nowrap`. |
| `-unity-text-overflow-position` | `start`, `middle`, `end`. |
| `-unity-text-align` | For example, `upper-left`, `middle-center`, `lower-right`. |
| `-unity-font-style`, `-unity-font-style-and-weight`, `font-weight` | Style: `normal`, `bold`, `italic`, `bold-and-italic`; `700` also selects bold. Arbitrary numeric weights are not supported. |
| `-unity-text-auto-size` | `none` or `best-fit 12px 24px`. |
| `-unity-text-outline-width` | A number without `px`, for example `1`. |
| `-unity-text-outline-color` | Color. |
| `-unity-text-outline` | Two tokens, for example `1px #000000`. |
| `text-shadow` | One shadow: `1px 2px 3 #000000` or `none`. The first two numbers are offsets; the third is blur without `px`. Use hex for the color. Multiple shadows are not implemented. |
| `-unity-text-generator` | Text rendering method, for example `standard`. Keep the game's setting for a regular interface. |
| `font-family` | Does not currently change the font; using it produces a warning. |
| `-unity-font-definition`, `-unity-font` | Loading a custom font through these properties is not supported in the game. |

Use the game's interface font and change its size, color, and style. Copying a font file into the module folder does not load it.

## Transforms, Transitions, and Mouse Input

| Properties | Values / use |
|---|---|
| `rotate` | `15deg`, `0.25turn`, `1rad`, `none`. A unitless number does not define an angle. |
| `scale` | `1.2` or `1.2 0.8`; `none` resets the scale. |
| `translate` | `10px 20px`, `50% 0`, `none`. |
| `transform-origin` | Configuring the pivot for rotation and scaling through USS does not currently work. |
| `transition-property` | Comma-separated property names, for example `opacity, scale`; also `all`, `none`. |
| `transition-duration`, `transition-delay` | Time in `s` or `ms`, with comma-separated lists: `0.2s`, `100ms, 200ms`. |
| `transition-timing-function` | `ease`, `ease-in`, `ease-out`, `ease-in-out`, `linear`; also combinations of `ease-in-`, `ease-out-`, or `ease-in-out-` with `sine`, `cubic`, `circ`, `elastic`, `back`, or `bounce`. Arbitrary `cubic-bezier(...)` is not parsed. |
| `transition` | For example, `opacity 0.2s ease-out 0s`; separate multiple transitions with commas. |
| `cursor` | `arrow`, `hand`, `text`, `move`, `resize-horizontal`, `resize-vertical`, `pipette`. |
| `picking-mode` | `ignore` makes the element itself pass through mouse target picking; any other value selects `Position`. Use `position` explicitly. This property does not control cursor visibility. |

A transition describes how an engine-animatable property changes when its value changes; it does not start an infinite animation by itself. To manage a window and cursor, use `UI:OpenWindow` / `UI:CloseWindow` as shown in the [short tutorial](./1.QuickStart.md).

Assigning a class from Lua is a convenient way to switch visual states:

```css
.panel { opacity: 1; }
.panel.dimmed { opacity: 0.4; }
```

```lua
root:EnableInClassList("dimmed", true)
root:EnableInClassList("dimmed", false)
```

This snippet assumes `root` has already been created. Class-management methods request that styles be applied again. Direct assignments such as `root.style.opacity = 0.4` use a separate Lua API; the `ElementStyle` property list is not the same as the USS property list.

## Unsupported Features

Unsupported properties are ignored, and a message about them can be found in the console. In particular, `all`, `gap`, `row-gap`, `column-gap`, `grid-template-columns`, `z-index`, `box-shadow`, `visibility`, `transform`, `animation`, and the `border` and `background` shorthands are not supported.

Use margins instead of `gap`, individual border properties instead of `border`, and `rotate` / `scale` / `translate` instead of `transform`. To hide an element and remove it from layout, use `display: none`.
