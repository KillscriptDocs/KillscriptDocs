# Storage

API для локального сохранения данных модулей.

---

## Storage

[ClientOnly] Автоматически загружаемая и сохраняемая таблица с данными модуля. Таблица может содержать string, number, boolean, nil и вложенные таблицы. Значения других типов молча игнорируются при сохранении.

```lua
Storage: table
```
