# Создание интерфейсов

В этом гайде рассматривается UI Toolkit: создание интерфейсов с разметкой UXML, стилями USS и обработкой действий игрока из Lua.

<a id="ui-or-imgui"></a>
## Когда использовать UI и ImGui

Для всего игрового HUD и любых элементов, которые часто обновляются во время игры, настоятельно рекомендуется использовать [API ImGui](../../api/ImGui.md). Частые изменения через UI вызывают повторные расчёты расположения и размеров элементов (layout), которые занимают существенное время главного потока. В идеале UI стоит использовать только для окон, обычно скрытых во время игрового процесса, например настроек или меню.

Также учитывайте задержку отображения: клиентские модули выполняются параллельно с игрой, а изменения UI применяются в начале следующего кадра. Единственное исключение - ImGui, нарисованный через него интерфейс отображается в том же кадре. Для всех элементов, которые должны позиционироваться относительно объектов в 3D-мире, например подписей над игроками, настоятельно рекомендуется ImGui.

Подробнее о параллельном выполнении модулей и применении результатов их работы - в [технических пояснениях](./5.Tech.md#client-module-execution).

<a id="1-custom-gui"></a>
## Из чего состоит интерфейс

UXML описывает дерево элементов: панели, надписи, кнопки и поля ввода. USS задаёт их оформление и расположение. Lua связывает интерфейс с игрой: обновляет данные и обрабатывает действия игрока.

Если вы знакомы с HTML и CSS, принципы будут похожи. Доступные в модулях элементы и стили перечислены во второй и третьей главах.

<a id="2-ui-toolkit-principles"></a>
## Файлы и создание UI

Все файлы `.uxml` и `.uss` должны находиться в папке `./ui` в корне модуля.

В них можно использовать изображения из папки `./images` модуля, указав относительный путь к файлу. Например, если файл стиля находится по пути `./ui/styles.uss`, то путь в нем до изображения `./images/icons/icon.png` будет выглядеть так: `url("../images/icons/icon.png")`.

Для файла разметки можно использовать такой шаблон:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="Root">

    </ui:VisualElement>
</ui:UXML>
```

У любого создаваемого объекта интерфейса обязательно должен быть один корневой `VisualElement`.

Элемент из UXML может быть создан как один из типов:

- Окно в произвольной части экрана, которое затем можно будет изменить в режиме редактирования UI, создается через `UI:BuildFromUxml()`
- Окно, которое позиционируется строго в центре и не может быть изменено через редактирование UI, создается через `UI:BuildFromUxmlAbsoluteCenter()`
- Окно, которое может быть закреплено в конкретной точке экрана и не может быть изменено через редактирование UI, создается через `UI:BuildFromUxmlAbsolute()`
- Элемент, который не будет добавлен на экран самостоятельно, но который после создания можно добавить как дочерний в другой, создается через `UI:CreateFromUxml()`
- Интерфейс с обработкой мыши, например меню с кнопками, создается через `UI:BuildFromUxmlInteractive()`. Для открытия окна с курсором используйте `UI:OpenWindow()`.

Также создать пустой элемент можно через `UI:CreateVisualElement()`.
