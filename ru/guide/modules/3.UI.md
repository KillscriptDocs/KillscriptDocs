# Пишем свой UI

Если модулю уже мало пары строк через `ImGui`, и нужен полноценный интерфейс с разметкой, стилями и динамическими блоками, удобнее перейти на UI Toolkit.

<a id="1-custom-gui"></a>
## 1. Когда модулю нужна своя GUI

Если модулю нужно не просто вывести пару строк через ImGui, а собрать полноценный интерфейс с блоками, строками, стилями и повторяющимися элементами, удобнее использовать UI Toolkit.

Верстка в UI Toolkit делается с помощью UXML и USS. По смыслу это очень похоже на связку HTML и CSS в веб-приложениях.

Подробнее узнать про UXML можно по ссылке: https://docs.unity3d.com/Manual/UIE-UXML.html

Подробнее узнать про USS можно по ссылке: https://docs.unity3d.com/Manual/UIE-USS.html

<a id="2-ui-toolkit-principles"></a>
## 2. Основные принципы работы с UI Toolkit через модуль

Все файлы `.uxml` и `.uss` должны находиться в папке `./ui` в корне модуля.

В них можно использовать изображения из папки `./images` модуля, указав относительный путь к файлу. Например, если файл стиля находится по пути `./ui/styles.uss`, то путь в нем до изображения `./images/icons/icon.png` будет выглядеть так: `url("../images/icons/icon.png")`.

Для файла разметки можно использовать такой шаблон:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements" xmlns:uie="UnityEditor.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="Root">
        
    </ui:VisualElement>
</ui:UXML>
```

У любого создаваемого объекта интерфейса обязательно должен быть один корневой `VisualElement`.

Элемент из UXML может быть создан как один из типов:

- Окно в произвольной части экрана, которое затем можно будет изменить в режиме редактирования UI, создается через `UI:BuildFromUxml()`
- Окно, которое позиционируется строго в центре и не может быть изменено через редактирование UI, создается через `UI:BuildFromUxmlAbsoluteCenter()`
- Окно, которое может быть закреплено в конкретной точке экрана и не может быть изменено через редактирование UI, создается через `UI:BuildFromUxmlAbsolute()`
- Элемент, который не будет добавлен на экран самостоятельно, но который после создания можно добавить как дочерний в другой, создается через `UI:CreateFromUxml()`

Также создать пустой элемент можно через `UI:CreateVisualElement()`.

<a id="3-ui-layout"></a>
## 3. Пошаговая верстка интерфейса

Сделаем небольшой модульный интерфейс, который показывает мини-статистику союзников по текущему раунду. Во время боя панель будет отображать живую статистику текущего раунда, а во время закупки - результаты предыдущего. Строки будут автоматически сортироваться по K/D, а их цвет будет меняться от зеленого у лучшего игрока до красного у худшего.

### 3.1. Создаем модуль и подготавливаем структуру

Через меню модулей создаем новый модуль и назовем его `Round KD Widget`.

В итоге структура будет такой:

```text
Round KD Widget/
├── module.json
├── localization.csv
├── scripts/
│   └── main.lua
└── ui/
    ├── RoundKdPanel.uxml
    ├── TeamKdRow.uxml
    └── styles.uss
```

### 3.2. Собираем корневую панель

Теперь создадим основную UXML-разметку панели. Она будет закреплена слева на экране, содержать заголовок, подпись и контейнер для строк игроков.

Открываем `ui/RoundKdPanel.uxml` и вставляем:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements" xmlns:uie="UnityEditor.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="Root" class="kd-panel">
        <ui:Label name="lblTitle" text="Round 1" class="kd-panel__title" />
        <ui:Label name="lblSubtitle" text="Current team round" class="kd-panel__subtitle" />
        <ui:VisualElement class="kd-panel__header">
            <ui:Label text="Player" class="kd-panel__header-name" />
            <ui:Label text="K" class="kd-panel__header-stat" />
            <ui:Label text="D" class="kd-panel__header-stat" />
            <ui:Label text="K/D" class="kd-panel__header-ratio" />
        </ui:VisualElement>
        <ui:VisualElement name="cntRows" class="kd-panel__rows" />
    </ui:VisualElement>
</ui:UXML>
```

Контейнер `cntRows` пока пустой. Строки игроков мы будем добавлять в него из Lua через `UI:CreateFromUxml()`, чтобы не дублировать разметку вручную.

### 3.3. Делаем шаблон строки, стили и локализацию

Один и тот же блок игрока удобнее вынести в отдельный шаблон. Тогда модуль сможет создавать столько строк, сколько реально нужно команде.

Создаем файл `ui/TeamKdRow.uxml`:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements" xmlns:uie="UnityEditor.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="cntRow" class="kd-row" style="width: 100%; flex-direction: row;">
        <ui:VisualElement name="veAccent" class="kd-row__accent" />
        <ui:VisualElement name="veBackground" class="kd-row__background" style="flex-direction: row; width: 100%;">
            <ui:Label name="lblNickname" text="Player" class="kd-row__name" />
            <ui:Label name="lblKills" text="0" class="kd-row__stat" />
            <ui:Label name="lblDeaths" text="0" class="kd-row__stat" />
            <ui:Label name="lblRatio" text="0.0" class="kd-row__ratio" />
        </ui:VisualElement>
    </ui:VisualElement>
</ui:UXML>
```

Чтобы модуль сразу был готов к разным языкам, добавим файл `localization.csv`. В нем: первая колонка - ключ строки, дальше переводы по языкам.

### 3.4. Подключаем UXML и создаем строки из шаблона

Сначала поднимем корневую панель и научим модуль создавать строки игроков через `UI:CreateFromUxml()`.

В начале `scripts/main.lua` добавляем:

```lua
local UiRoot = nil
local lblTitle = nil
local lblSubtitle = nil
local cntRows = nil

local RowElements = {}

local function EnsureUi()
    if UiRoot then
        return true
    end

    UiRoot = UI:BuildFromUxmlAbsolute("RoundKdPanel.uxml")
    if not UiRoot then
        return false
    end

    lblTitle = UiRoot:GetChild("lblTitle")
    lblSubtitle = UiRoot:GetChild("lblSubtitle")
    cntRows = UiRoot:GetChild("cntRows")

    return true
end

local function CreateRowElement()
    local rowRoot = UI:CreateFromUxml("TeamKdRow.uxml")
    if not rowRoot then
        return nil
    end

    cntRows:Add(rowRoot)

    return {
        root = rowRoot,
        veAccent = rowRoot:GetChild("veAccent"),
        veBackground = rowRoot:GetChild("veBackground"),
        lblNickname = rowRoot:GetChild("lblNickname"),
        lblKills = rowRoot:GetChild("lblKills"),
        lblDeaths = rowRoot:GetChild("lblDeaths"),
        lblRatio = rowRoot:GetChild("lblRatio")
    }
end
```

Здесь важно два момента:

- `UI:BuildFromUxmlAbsolute()` сразу добавляет панель в корень UI, поэтому она всегда висит слева на экране
- `UI:CreateFromUxml()` удобно использовать для повторяющихся блоков, например строк таблицы

### 3.5. Считаем статистику по раундам и красим строки

Теперь дописываем полную логику. Она будет:

- сохранять стартовые значения K и D в начале каждого раунда
- считать дельту относительно начала раунда
- кешировать результаты прошлого раунда при смене `RoundId`
- во время закупки показывать прошлый раунд, а во время боя - текущий
- брать все пользовательские строки через `Localization:GetTranslation(...)`
- сортировать союзников по K/D и раскрашивать строки от зеленого к красному

Готовый `scripts/main.lua`:

```lua
local UiRoot = nil
local lblTitle = nil
local lblSubtitle = nil
local cntRows = nil

local RowElements = {}
local LastRoundId = nil
local RoundStartStats = {}
local PreviousRoundRows = nil
local PreviousRoundId = nil

local function GetAgentStats(agent)
    return agent and agent.Stats or nil
end

local function CopyScore(stats)
    return {
        Kills = stats and stats.Kills or 0,
        Deaths = stats and stats.Deaths or 0
    }
end

local function GetDisplayRatio(kills, deaths)
    if deaths <= 0 then
        return kills
    end

    return kills / deaths
end

local function FormatRatio(kills, deaths)
    return string.format("%.1f", GetDisplayRatio(kills, deaths))
end

local function GetRankColor(index, total)
    local progress = 0
    if total > 1 then
        progress = (index - 1) / (total - 1)
    end

    local r = 0.25 + (0.92 - 0.25) * progress
    local g = 0.85 + (0.34 - 0.85) * progress
    local b = 0.45 + (0.34 - 0.45) * progress

    return Color.new(r, g, b, 1.0), Color.new(r, g, b, 0.16)
end

local function EnsureUi()
    if UiRoot then
        return true
    end

    UiRoot = UI:BuildFromUxmlAbsolute("RoundKdPanel.uxml")
    if not UiRoot then
        return false
    end

    lblTitle = UiRoot:GetChild("lblTitle")
    lblSubtitle = UiRoot:GetChild("lblSubtitle")
    cntRows = UiRoot:GetChild("cntRows")

    return true
end

local function CreateRowElement()
    local rowRoot = UI:CreateFromUxml("TeamKdRow.uxml")
    if not rowRoot then
        return nil
    end

    cntRows:Add(rowRoot)

    return {
        root = rowRoot,
        veAccent = rowRoot:GetChild("veAccent"),
        veBackground = rowRoot:GetChild("veBackground"),
        lblNickname = rowRoot:GetChild("lblNickname"),
        lblKills = rowRoot:GetChild("lblKills"),
        lblDeaths = rowRoot:GetChild("lblDeaths"),
        lblRatio = rowRoot:GetChild("lblRatio")
    }
end

local function EnsureRowElements(count)
    while #RowElements < count do
        local rowElement = CreateRowElement()
        if not rowElement then
            break
        end

        table.insert(RowElements, rowElement)
    end

    for i = 1, #RowElements do
        RowElements[i].root.style.display = i <= count and DisplayStyle.Flex or DisplayStyle.None
    end
end

local function SnapshotRoundStart()
    RoundStartStats = {}

    if not DefusalGame then
        return
    end

    local agents = Agents:GetAll()
    for i = 1, agents.Length do
        local agent = agents[i]
        RoundStartStats[agent] = CopyScore(GetAgentStats(agent))
    end
end

local function BuildTeamRows(team)
    local rows = {}
    if not DefusalGame or not team then
        return rows
    end

    local agents = Agents:GetAll()
    for i = 1, agents.Length do
        local agent = agents[i]
        local stats = GetAgentStats(agent)

        if agent and agent.Team == team and stats and stats.IsConnected ~= false then
            local startStats = RoundStartStats[agent] or { Kills = 0, Deaths = 0 }
            local kills = math.max(0, (stats.Kills or 0) - (startStats.Kills or 0))
            local deaths = math.max(0, (stats.Deaths or 0) - (startStats.Deaths or 0))

            table.insert(rows, {
                Nickname = agent.Nickname,
                Kills = kills,
                Deaths = deaths,
                Ratio = GetDisplayRatio(kills, deaths),
                IsAlive = stats.IsAlive == true
            })
        end
    end

    table.sort(rows, function(a, b)
        if a.Ratio ~= b.Ratio then
            return a.Ratio > b.Ratio
        end

        if a.Kills ~= b.Kills then
            return a.Kills > b.Kills
        end

        if a.Deaths ~= b.Deaths then
            return a.Deaths < b.Deaths
        end

        return a.Nickname < b.Nickname
    end)

    return rows
end

local function CloneRows(rows)
    local result = {}

    for i = 1, #rows do
        local row = rows[i]
        result[i] = {
            Nickname = row.Nickname,
            Kills = row.Kills,
            Deaths = row.Deaths,
            Ratio = row.Ratio,
            IsAlive = true
        }
    end

    return result
end

local function HandleRoundChange(localTeam)
    if not DefusalGame then
        return
    end

    if LastRoundId == nil then
        LastRoundId = DefusalGame.RoundId
        SnapshotRoundStart()
        return
    end

    if DefusalGame.RoundId == LastRoundId then
        return
    end

    if localTeam and LastRoundId > 0 then
        PreviousRoundRows = CloneRows(BuildTeamRows(localTeam))
        PreviousRoundId = LastRoundId
    end

    LastRoundId = DefusalGame.RoundId
    SnapshotRoundStart()
end

local function DrawRows(rows)
    EnsureRowElements(#rows)

    for i = 1, #rows do
        local row = rows[i]
        local refs = RowElements[i]
        local accentColor, backgroundColor = GetRankColor(i, #rows)

        refs.veAccent.style.backgroundColor = accentColor
        refs.veBackground.style.backgroundColor = backgroundColor
        refs.lblKills.style.color = accentColor
        refs.lblRatio.style.color = accentColor
        refs.root.style.opacity = row.IsAlive and 1.0 or 0.55

        refs.lblNickname.text = row.Nickname
        refs.lblKills.text = tostring(row.Kills)
        refs.lblDeaths.text = tostring(row.Deaths)
        refs.lblRatio.text = FormatRatio(row.Kills, row.Deaths)
    end
end

local function Tick()
    if not EnsureUi() then
        return
    end

    if not DefusalGame or DefusalGame.IsGameEnded then
        UiRoot.visible = false
        return
    end

    local localAgent = Agents:GetLocalAgent()
    if not localAgent then
        UiRoot.visible = false
        return
    end

    UiRoot.visible = true

    local localTeam = localAgent.Team
    HandleRoundChange(localTeam)

    local rows = nil
    if DefusalGame.Stage == EDefusalRoundStage.Buy and PreviousRoundRows and #PreviousRoundRows > 0 then
        lblTitle.text = Localization:GetTranslation("RoundResults") .. " " .. tostring(PreviousRoundId)
        lblSubtitle.text = Localization:GetTranslation("PreviousRoundDuringBuy")
        rows = PreviousRoundRows
    else
        if DefusalGame.RoundId <= 0 then
            lblTitle.text = Localization:GetTranslation("Warmup")
        else
            lblTitle.text = Localization:GetTranslation("Round") .. " " .. tostring(DefusalGame.RoundId)
        end

        lblSubtitle.text = Localization:GetTranslation("CurrentTeamRound")
        rows = BuildTeamRows(localTeam)
    end

    DrawRows(rows)
end

Scheduler:OnFrame(Tick)
```

Здесь схема простая:

- в `UXML` статические надписи вроде `Player` или `K/D` лучше задавать через `LocalizedLabel`
- в `Lua` динамические строки вроде `Round 5` или `Round results 4` удобнее собирать через `Localization:GetTranslation(...)`

На этом базовый интерфейс готов. Мы получили небольшой HUD-блок слева, который не требует ручного дублирования строк и хорошо показывает, как комбинировать `BuildFromUxmlAbsolute()`, `CreateFromUxml()` и обновление данных из Lua.
