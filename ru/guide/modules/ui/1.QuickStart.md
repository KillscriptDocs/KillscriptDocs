# Первый интерфейс модуля

[Создание интерфейсов](../3.UI.md) · Глава 1 из 4 · [Далее: разметка UXML](./2.UXML.md)

Сделаем небольшую панель со счётчиком нажатий и кнопкой закрытия. Для этого нужны три файла: UXML описывает элементы, USS задаёт оформление, Lua обрабатывает нажатия.

## 1. Подготовьте модуль

Создайте обычный модуль без Reflex по [инструкции для начинающих](../2.Start.md#2-first-module). Оставьте созданный игрой `module.json`, а файлы примера расположите так:

```text
Мой первый интерфейс/
├── module.json
├── scripts/
│   └── main.lua
└── ui/
    ├── Counter.uxml
    └── counter.uss
```

## 2. Добавьте разметку

Содержимое `ui/Counter.uxml`:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <Style src="./counter.uss" />
    <ui:VisualElement name="Root" class="counter-panel">
        <ui:Label text="Мой первый интерфейс" class="counter-title" />
        <ui:Label name="CountLabel" text="Нажатий: 0" />
        <ui:Button name="CountButton" text="Нажать" class="counter-button" />
        <ui:Button name="CloseButton" text="Закрыть" class="counter-button" />
    </ui:VisualElement>
</ui:UXML>
```

Внутри `UXML` должен быть один корневой визуальный элемент. `Style` подключает таблицу стилей и не создаёт элемент на экране. `name` позволяет найти элемент из Lua, а `class` связывает его с правилами USS. Текст задаётся атрибутом `text`, а не между открывающим и закрывающим тегами.

## 3. Добавьте оформление

Содержимое `ui/counter.uss`:

```css
.counter-panel {
    position: absolute;
    left: 40px;
    top: 140px;
    width: 280px;
    padding: 16px;
    background-color: rgb(20, 26, 36);
    border-radius: 8px;
    color: rgb(240, 240, 240);
    font-size: 16px;
}

.counter-title {
    font-size: 20px;
    margin-bottom: 12px;
}

.counter-button {
    height: 36px;
    margin-top: 8px;
    background-color: rgb(45, 65, 95);
    color: rgb(255, 255, 255);
}

.counter-button:hover {
    background-color: rgb(65, 90, 125);
}
```

Получится тёмная панель слева сверху с заголовком, счётчиком и двумя кнопками друг под другом. `position: absolute` задаёт положение панели через `left` и `top`; размеры указаны в единицах UI, поэтому итоговый размер на экране зависит от масштаба интерфейса. `.counter-button` оформляет обе кнопки, а `:hover` меняет их фон при наведении.

## 4. Подключите Lua

Замените содержимое `scripts/main.lua`:

```lua
local root = UI:BuildFromUxmlInteractive("Counter.uxml")
if not root then
    print("Не удалось создать интерфейс. Проверьте ошибки UXML в консоли.")
    return
end

local countLabel = root:GetChild("CountLabel")
local countButton = root:GetChild("CountButton")
local closeButton = root:GetChild("CloseButton")
if not countLabel or not countButton or not closeButton then
    print("Не найдены элементы интерфейса. Проверьте атрибуты name.")
    root:Delete()
    return
end

local count = 0

countButton:OnClick(function()
    count = count + 1
    countLabel.text = "Нажатий: " .. count
end)

closeButton:OnClick(function()
    UI:CloseWindow(root)
end)

if not UI:OpenWindow(root, true, true, false, false) then
    print("Не удалось открыть окно.")
    root:Delete()
end
```

`BuildFromUxmlInteractive` создаёт элемент и добавляет его на экран с обработкой мыши. В аргументе указано имя файла из `ui`, без префикса `ui/`.

`GetChild` ищет потомка по `name`, включая вложенные элементы, и возвращает `nil`, если ничего не найдено. `OnClick` устанавливает обработчик клика.

`OpenWindow(root, true, true, false, false)` открывает окно, разблокирует курсор и блокирует игровой ввод. Последние два `false` отключают скрытие перекрываемого UI и размытие фона. `CloseWindow` скрывает панель и снимает её запросы на курсор и блокировку ввода; если открыты другие окна, они могут продолжать удерживать курсор.

Создавайте панель один раз, как здесь, а не на каждом кадре. Изменения UI, в том числе текста счётчика, применяются в начале следующего кадра. Для игрового HUD и часто обновляемых элементов настоятельно рекомендуется ImGui, а UI лучше использовать для окон, обычно скрытых во время игры. Причины и рекомендации по выбору API описаны в [основном гайде](../3.UI.md#ui-or-imgui).

## 5. Проверьте в игре

![](../../../../images/counter_ui.png)

1. Включите модуль и зайдите на карту пользовательского сервера: в главном меню Lua-код модулей не выполняется.
2. Нажмите «Нажать» несколько раз: счётчик должен увеличиваться.
3. Нажмите «Закрыть»: панель должна исчезнуть, а управление вернуться к игре, если его не удерживает другое окно.
4. Измените `width: 280px` на `width: 340px` и сохраните USS. Для локального модуля из папки изменение файла вызывает перезагрузку. Панель создастся заново, а счётчик вернётся к нулю. Если автоперезагрузка не сработала, выключите и снова включите модуль.

| Проблема | Что проверить |
|---|---|
| Панель не появилась | Модуль включён, карта загружена, файлы лежат в `ui`; в консоли нет ошибок Lua или UXML. |
| Кнопки не нажимаются | Используется интерактивное создание и вызван `OpenWindow`; другое окно не перекрывает панель. |
| Элемент не найден | Регистр и написание `name` совпадают с аргументом `GetChild`. |
| Стиль не применился | `Style src` и имя USS совпадают, класс указан и в UXML, и в USS. |

Надписи здесь написаны прямо в коде, чтобы пример оставался коротким. Для публикуемого модуля вынесите их в `localization.csv`; пример `LocalizedLabel` есть в [главе с панелью статистики](./4.RoundStats.md).
