# Поддержка UXML в модулях

[Создание интерфейсов](../3.UI.md) · Глава 2 из 4 · [Назад: первый интерфейс](./1.QuickStart.md) · [Далее: оформление USS](./3.USS.md)

UXML определяет, какие элементы появятся в вашем интерфейсе и как они вложены друг в друга. Здесь перечислены доступные в модулях теги и атрибуты, с примерами их использования.

## Структура документа

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="Root">
        <ui:Label text="Привет!" />
    </ui:VisualElement>
</ui:UXML>
```

Файлы `.uxml` и `.uss` размещаются в `ui` внутри модуля. Используйте один корневой `VisualElement`. Объявление `xmlns:ui="UnityEngine.UIElements"` позволяет писать стандартные элементы с префиксом `ui:`; скопируйте его из примера.

| Конструкция | Поддержка и применение |
|---|---|
| `ui:UXML` | Оболочка документа. |
| `Style`, `ui:Style` | Подключение USS через `src`; также читается текст USS внутри тега. Для примеров удобнее отдельный файл. |
| `ui:Template` | Объявление шаблона: `name` задаёт псевдоним, `src` — файл UXML. Объявляйте до использования. |
| `ui:Instance` | `template` выбирает объявленный шаблон. Создаётся дополнительный `VisualElement`, внутрь которого помещается корень шаблона; к оболочке применяются общие атрибуты. |
| `AttributeOverrides`, привязки данных, произвольные теги | Не поддерживаются. Используйте элементы из таблицы ниже, а данные и поведение задавайте через Lua. |

Пример использования файла `ui/Row.uxml` с одним корнем:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <ui:Template name="Row" src="Row.uxml" />
    <ui:VisualElement name="Root">
        <ui:Instance template="Row" name="FirstRow" />
        <ui:Instance template="Row" name="SecondRow" />
    </ui:VisualElement>
</ui:UXML>
```

Поиск файла шаблона выполняется по имени файла: не рассчитывайте на различение двух `Row.uxml` в разных подпапках. Не создавайте циклические ссылки шаблонов. Для динамического списка используйте `UI:CreateFromUxml("Row.uxml")` и `container:Add(row)`.

## Общие атрибуты

Эти атрибуты доступны всем элементам из следующей таблицы. Имена атрибутов пишите точно как указано; неизвестный атрибут может быть пропущен без сообщения об ошибке.

| Атрибут | Значение / начальное значение | Для чего нужен |
|---|---|---|
| `name` | Строка; `""` | Поиск через `GetChild("Name")` и селектор `#Name`. |
| `class` | Имена через пробел | Например, `class="panel compact"` соответствует `.panel` и `.compact`. |
| `style` | Объявления USS | Например, `style="width: 100%; height: 40px;"`. |
| `enabled` | `true` / `false`; `true` | Включённость элемента. Это не управление видимостью. |
| `picking-mode` | `Position` / `Ignore`; `Position` | Участие самого элемента в выборе цели мыши. `Ignore` не отключает автоматически всех потомков. Методы создания UI могут переопределить режим корня. |
| `focusable` | `true` / `false`; `true` | Возможность получать фокус. |
| `tabindex` | Целое число; `0` | Индекс перехода фокуса. Именно `tabindex`, без дефиса. |
| `tooltip` | Строка; `""` | Передаётся в свойство подсказки элемента; её показ зависит от UI игры. |
| `view-data-key` | Строка; `""` | Служебный ключ состояния элемента. Для сохранения настроек модуля используйте `Config` или `Storage`. |
| `usage-hints` | По умолчанию `None` | Служебная настройка; для обычного интерфейса оставьте значение по умолчанию. |
| `language-direction` | `Inherit`, `LTR`, `RTL`; `Inherit` | Направление текста. |

## Элементы и дополнительные атрибуты

Столбец «Вложенность» показывает, можно ли добавлять внутрь элемента другие UXML-теги. При «нет» вложенная разметка игнорируется: настраивайте элемент атрибутами и через Lua. Для группировки и расположения элементов используйте прежде всего `VisualElement`, `ScrollView`, `Foldout` и `GroupBox`.

Обозначение **текстовые атрибуты**: `text` (строка, по умолчанию пустая), `enable-rich-text` и `parse-escape-sequences` (логические, по умолчанию `false`). Текст между тегами не заменяет `text`. Rich text внутри XML-атрибута требует экранирования, например `text="&lt;b&gt;Важно&lt;/b&gt;"`.

| Тег | Назначение и дополнительные атрибуты | Вложенность | Тип в Lua |
|---|---|:---:|---|
| `ui:VisualElement` | Контейнер; только общие атрибуты | Да | `VisualElement` |
| `ui:TextElement` | Текстовые атрибуты | Да | `TextElement` |
| `ui:Label` | Надпись; текстовые атрибуты | Да | `LabelElement` |
| `ui:GroupBox` | Группа с заголовком `text` | Да | `VisualElement` |
| `ui:Button` | Текстовые атрибуты; `click-sound-event`, `additional-click-sound-event` (строки), `disable-click-sound` (логическое) | Да | `ButtonElement` |
| `ui:Toggle` | `label` (строка), `value` (логическое) | Нет | `ToggleElement` |
| `ui:Scroller` | `low-value`, `high-value`, `value` (числа), `direction` | Нет | `ScrollerElement` |
| `ui:ScrollView` | `mode`; `horizontal-scroller-visibility`, `vertical-scroller-visibility`; логические `show-horizontal` / `show-horizontal-scroller`, `show-vertical` / `show-vertical-scroller` | Да | `ScrollViewElement` |
| `ui:Foldout` | Раскрывающаяся группа: `text` (строка), `value` (логическое) | Да | `FoldoutElement` |
| `ui:Slider` | `label`; `low-value`, `high-value`, `value`, `page-size` (числа); `direction`; `show-input-field`, `inverted` (логические) | Нет | `SliderElement` |
| `ui:SliderInt` | Как `Slider`, но границы и значение целочисленные | Нет | `SliderIntElement` |
| `ui:MinMaxSlider` | `label`; `min-value`, `max-value`, `low-limit`, `high-limit` (числа) | Нет | `MinMaxSliderElement` |
| `ui:DropdownField` | `label`; `value` — варианты через запятую; `index` — выбранный индекс с нуля, по умолчанию `-1` | Нет | `DropdownFieldElement` |
| `ui:Dropdown` | Псевдоним `DropdownField` с теми же атрибутами; используйте основное имя `ui:DropdownField` | Нет | `DropdownFieldElement` |
| `ui:RadioButton` | `label` (строка), `value` (логическое) | Нет | `RadioButtonElement` |
| `ui:RadioButtonGroup` | `label`; `choices` — варианты через запятую; `value` — индекс с нуля, по умолчанию `-1` | Нет | `VisualElement` |
| `ui:ProgressBar` | `title`; `low-value`, `high-value`, `value` (числа; по умолчанию `0`, `100`, `0`) | Нет | `ProgressBarElement` |
| `ui:Image` | Только общие атрибуты; `src`, `image`, `sprite` не читаются | Да | `ImageElement` |
| `ui:IntegerField` | `label` (строка), `value` (целое число) | Нет | `IntegerFieldElement` |
| `ui:FloatField` | `label` (строка), `value` (число) | Нет | `FloatFieldElement` |
| `ui:TextField` | `label`, `value` (строки), `max-length` (целое число), `multiline`, `is-read-only` (логические) | Нет | `TextFieldElement` |
| `ColorField` | Выбор цвета: `value`, `default-value` (цвета), `show-reset-button` (логическое) | Нет | `ColorFieldElement` |
| `LocalizedLabel` | `text`, `localization-key` (строки), `enable-rich-text`, `parse-escape-sequences` (логические) | Да | `LocalizedLabelElement` |
| `KeyTip` | Подсказка клавиши: `action-path`, `prefix`, `suffix` (строки), `force-text-mode` (логическое) | Да | `KeyTipElement` |
| `Painter` | Рисование из Lua: `line-cap`, `line-join` | Да | `PainterElement` |

`ColorField`, `LocalizedLabel`, `KeyTip` и `Painter` пишутся без префикса `ui:`. Из Lua у `GroupBox` и `RadioButtonGroup` доступны только общие свойства и методы `VisualElement`; специальных свойств для управления группой нет.

Для `direction` используйте `Horizontal` или `Vertical`; для `ScrollView.mode` — `Vertical`, `Horizontal`, `VerticalAndHorizontal`; для видимости полос — `Auto`, `AlwaysVisible`, `Hidden`. Не задавайте одновременно старые логические атрибуты показа полос и новые атрибуты видимости.

У `ScrollView` по умолчанию обе полосы скрыты. Чтобы показывать вертикальную полосу по необходимости, задайте `vertical-scroller-visibility="Auto"`. Варианты выпадающего списка задавайте атрибутом `value`, а не вложенными элементами.

У `Slider`, `SliderInt` и `Scroller` исходные границы равны нулю: задавайте диапазон явно; доступные свойства Lua смотрите в [UI API](../../../api/UI.md).

Пример выбора варианта и числового значения:

```xml
<ui:DropdownField name="Mode" label="Режим" value="Обычный,Компактный" index="0" />
<ui:Slider name="Size" label="Размер" low-value="10" high-value="100" value="40" />
```

Это фрагмент для размещения внутри корневого элемента. Запятая разделяет варианты списка, пробелы по краям удаляются; запятую внутри одного варианта этот формат не экранирует.

Для изображения используйте `background-image` из [USS](./3.USS.md#images), либо методы `ImageElement` из Lua. Например, контейнеру можно назначить класс `icon` и стиль `.icon { width: 32px; height: 32px; background-image: url("../images/icon.png"); }`.
