# Поддержка USS в модулях

[Создание интерфейсов](../3.UI.md) · Глава 3 из 4 · [Назад: разметка UXML](./2.UXML.md) · [Далее: панель статистики](./4.RoundStats.md)

USS задаёт оформление элементов UXML: размеры, расположение, цвета, текст и изображения. Здесь собраны доступные свойства, примеры значений и ограничения, которые стоит учитывать при создании интерфейса модуля.

## Как подключить стили

Создайте `ui/styles.uss` и подключите его перед корневым элементом:

```xml
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <Style src="./styles.uss" />
    <ui:VisualElement name="Root" class="panel">
        <ui:Label name="Title" text="Настройки" />
    </ui:VisualElement>
</ui:UXML>
```

```css
.panel {
    width: 300px;
    padding: 12px;
    background-color: rgb(20, 26, 36);
}

#Title {
    color: rgb(255, 255, 255);
    font-size: 18px;
}
```

Для USS в подпапке используйте путь от `ui`, например `src="themes/dark.uss"`, даже если сам UXML находится в другой подпапке. В начале пути можно указать `./`.

## Селекторы, состояния и переменные

| Синтаксис | Поддержка / пример |
|---|---|
| `*` | Все элементы. |
| `Label` | Имя типа без `ui:`. Для собственных элементов имя типа может отличаться от короткого UXML-тега; удобнее использовать классы. |
| `.panel`, `#Title` | Класс и `name` элемента. |
| `.panel.compact`, `Label.title` | Сочетание условий для одного элемента. |
| `.panel Label` | Потомок на любой глубине. |
| `.panel > Label` | Непосредственный ребёнок. |
| `.title + .subtitle`, `.title ~ .row` | Следующий сосед / последующие соседи с тем же родителем. |
| `.title, .subtitle` | Несколько селекторов для одного правила. |
| `:first-child`, `:last-child` | Первый / последний ребёнок родителя. |
| `:enabled`, `:disabled` | Собственная включённость элемента. Отключение родителя само по себе не переключает этот селектор у ребёнка. |
| `:hover` | Состояние при наведении мыши. Начните с простого `.button:hover`; для выхода из наведения задавайте обычное значение того же свойства в `.button`. |
| `:root` | Используйте для объявления общих переменных. Для оформления конкретной панели удобнее её класс. |
| `:focus`, `:active`, `:checked`, `:nth-child(...)`, `:not(...)`, селекторы атрибутов | Не поддерживаются. Для состояния используйте классы и Lua. |

Если несколько правил меняют одно свойство, предпочитайте простые селекторы: имя `#Title` имеет приоритет над классом `.title`, а класс — над типом `Label`. Стиль в атрибуте `style` UXML применяется после обычных правил USS. Для сложных сочетаний не рассчитывайте на полное совпадение с CSS в браузере; `!important` не используйте.

Объявляйте переменные в отдельном `:root`:

```css
:root {
    --panel-color: #141A24;
    --panel-padding: 12px;
}

.panel {
    background-color: var(--panel-color);
    padding: var(--panel-padding);
}
```

Объявляйте используемые переменные явно в `:root`: они общие для подключённых стилей этого интерфейса. Объявление переменной внутри `.panel` не создаёт отдельное значение для этой панели. Запасное значение в `var(--name, #FFFFFF)` не заменяет объявления переменных: если ни одной переменной нет, оно может не сработать. Избегайте вложенных функций в запасном значении.

`@import`, `@media` и `@keyframes` не поддерживаются. Несколько USS подключайте отдельными `Style`; анимации задавайте переходами ниже или через `ScheduleAnimation` в Lua.

## Форматы значений

| Формат | Как использовать |
|---|---|
| Длина | `12px`, `50%`, `0`; число без единицы считается пиксельной длиной. `%` имеет смысл только для свойств, поддерживающих относительные размеры. |
| Ключевые длины | `auto` и `none`; применимость зависит от свойства. Например, `width: auto`, `max-width: none`. |
| Число | `0.5`, `1`, `24`; десятичный разделитель — точка. |
| Цвет | `#RRGGBB`, `#RRGGBBAA`, `rgb(20, 40, 60)`, `rgba(20, 40, 60, 0.5)`. Каналы RGB — от 0 до 255, альфа — от 0 до 1. |
| Логические UXML-значения | `true` / `false`; они не заменяют значения USS вроде `display: none`. |

Единицы `em`, `rem`, `vw`, `vh` и вычисления `calc(...)` не реализованы как соответствующие CSS-величины. Неизвестная единица может быть прочитана как пиксели, а ошибочное значение — как ноль: отсутствие ошибки не доказывает поддержку.

## Свойства раскладки

Свойства сгруппированы по назначению. В столбце справа указаны допустимые значения и примеры. Некоторые привычные свойства пока недоступны в игре — это отмечено отдельно.

| Свойства | Значения / применение |
|---|---|
| `width`, `height`, `min-width`, `min-height`, `max-width`, `max-height` | Длины, например `width: 100%`, `min-height: 32px`. |
| `position` | `relative`, `absolute`. |
| `left`, `right`, `top`, `bottom` | Длины; например `right: 20px; bottom: 20px`. |
| `display` | `flex`, `none`; `none` исключает элемент из раскладки. |
| `flex-direction` | `row`, `column`, `row-reverse`, `column-reverse`. |
| `flex-wrap` | `nowrap`, `wrap`, `wrap-reverse`. |
| `flex-grow`, `flex-shrink` | Числовые коэффициенты, например `flex-grow: 1`. |
| `flex-basis` | Начальный размер по основной оси: длина или `auto`. |
| `flex` | `none`, `auto`, `initial`, либо рост, сжатие и размер: `1 1 0%`. |
| `align-content`, `align-items`, `align-self` | Выравнивание по поперечной оси: например, `flex-start`, `center`, `flex-end`, `stretch`. Используйте `auto` для `align-self`, чтобы следовать выравниванию родителя. |
| `justify-content` | `flex-start`, `center`, `flex-end`, `space-between`, `space-around`, `space-evenly`. |
| `margin`, `margin-top`, `margin-right`, `margin-bottom`, `margin-left` | Внешние отступы; сокращение принимает 1–4 длины через пробел. |
| `padding`, `padding-top`, `padding-right`, `padding-bottom`, `padding-left` | Внутренние отступы; сокращение принимает 1–4 длины через пробел. |
| `aspect-ratio` | Положительное число, отношение `16 / 9` или `auto`. |
| `overflow` | `visible`, `hidden`. |
| `-unity-overflow-clip-box` | `padding-box`, `content-box`. |

Для четырёх значений отступов порядок: верх, право, низ, лево. Для двух — вертикаль и горизонталь. Пример: `padding: 8px 12px`.

Пример строки с растягивающимся именем и фиксированным счётчиком:

```css
.row {
    flex-direction: row;
    align-items: center;
    height: 32px;
}

.row-name {
    width: 0;
    flex-grow: 1;
    overflow: hidden;
    white-space: nowrap;
    text-overflow: ellipsis;
}

.row-count {
    width: 48px;
    margin-left: 8px;
}
```

## Фон, рамки и изображения

| Свойства | Значения / применение |
|---|---|
| `background-color` | Цвет. |
| `background-image` | `none` или `url("../images/icon.png")`; путь обязательно заключайте в кавычки внутри `url`. |
| `background-position` | Например, `center center`, `left top`, `right 8px bottom 8px`. |
| `background-position-x`, `background-position-y` | Положение по оси: `center`, `left 8px` для X, `top 8px` для Y; также длина. |
| `background-size` | `cover`, `contain`, `auto`, одна или две длины. Одна длина задаёт обе оси: `32px` означает `32px 32px`. |
| `background-repeat` | `repeat`, `no-repeat`, `round`, `space`, `repeat-x`, `repeat-y`; можно задать два значения по осям. |
| `-unity-background-image-tint-color` | Цветовой множитель изображения. |
| `-unity-background-scale-mode` | `stretch-to-fill`, `scale-and-crop`, `scale-to-fit`. |
| `border-color`, `border-top-color`, `border-right-color`, `border-bottom-color`, `border-left-color` | Цвета сторон. В сокращении `border-color` используйте hex без пробелов: `#FFFFFF #808080`. |
| `border-width`, `border-top-width`, `border-right-width`, `border-bottom-width`, `border-left-width` | Толщина в пикселях. Сокращение принимает 1–4 значения. |
| `border-radius`, `border-top-left-radius`, `border-top-right-radius`, `border-bottom-right-radius`, `border-bottom-left-radius` | Радиусы. В сокращении порядок: левый верхний, правый верхний, правый нижний, левый нижний. Синтаксис с `/` не реализован. |
| `-unity-slice-left`, `-unity-slice-top`, `-unity-slice-right`, `-unity-slice-bottom` | Целые размеры краёв для изображения из девяти частей, например `4`. |
| `-unity-slice-scale` | Числовой масштаб краёв. |
| `-unity-slice-type` | Способ заполнения изображения из девяти частей, например `sliced`. |
| `opacity` | Число от `0` до `1`; нулевая прозрачность не удаляет элемент из раскладки. |
| `filter` | Реализованы `blur`, `contrast`, `grayscale`, `hue-rotate`, `invert`, `opacity`, `sepia`, `tint`; пример `blur(2px)` или `tint(#FFFFFF)`. `none` очищает список. |

Сокращения рамок и отступов разбиваются по пробелам, поэтому `border-color: rgb(20, 40, 60)` не является надёжным форматом сокращения. Используйте `border-color: #14283C` либо отдельные свойства сторон с `rgb(...)`.

### Как добавить картинку

Положите `icon.png` в `images` в корне модуля. Поддерживаются `.png`, `.jpg`, `.jpeg`; SVG не поддерживается.

```css
.icon {
    width: 32px;
    height: 32px;
    background-image: url("../images/icon.png");
    background-size: contain;
    background-repeat: no-repeat;
}
```

В UXML достаточно `<ui:VisualElement class="icon" />`. Указывайте картинку из папки модуля; ссылки на изображения в интернете не поддерживаются. Для вложенной картинки используйте, например, `../images/icons/icon.png`.

## Текст

| Свойства | Значения / применение |
|---|---|
| `color` | Цвет текста. |
| `font-size` | Размер, например `16px`. |
| `letter-spacing`, `word-spacing`, `-unity-paragraph-spacing` | Длины: расстояния между буквами, словами, абзацами. |
| `white-space` | `normal`, `nowrap`. |
| `text-overflow` | `clip`, `ellipsis`; для многоточия также ограничьте ширину и задайте `overflow: hidden; white-space: nowrap`. |
| `-unity-text-overflow-position` | `start`, `middle`, `end`. |
| `-unity-text-align` | Например, `upper-left`, `middle-center`, `lower-right`. |
| `-unity-font-style`, `-unity-font-style-and-weight`, `font-weight` | Начертание: `normal`, `bold`, `italic`, `bold-and-italic`; `700` также задаёт жирное начертание. Произвольные числовые веса не поддерживаются. |
| `-unity-text-auto-size` | `none` либо `best-fit 12px 24px`. |
| `-unity-text-outline-width` | Число без `px`, например `1`. |
| `-unity-text-outline-color` | Цвет. |
| `-unity-text-outline` | Два токена, например `1px #000000`. |
| `text-shadow` | Одна тень: `1px 2px 3 #000000` или `none`. Первые два числа — смещение, третье — размытие без `px`. Для цвета используйте hex; несколько теней не реализованы. |
| `-unity-text-generator` | Способ отображения текста, например `standard`. Для обычного интерфейса оставьте настройку игры. |
| `font-family` | Пока не меняет шрифт; при использовании появляется предупреждение. |
| `-unity-font-definition`, `-unity-font` | Подключение своего шрифта через эти свойства в игре не поддерживается. |

Используйте шрифт интерфейса игры и меняйте его размер, цвет и начертание. Копирование файла шрифта в папку модуля не подключит его.

## Преобразования, переходы и мышь

| Свойства | Значения / применение |
|---|---|
| `rotate` | `15deg`, `0.25turn`, `1rad`, `none`. Число без единицы не задаёт угол. |
| `scale` | `1.2` либо `1.2 0.8`; `none` сбрасывает масштаб. |
| `translate` | `10px 20px`, `50% 0`, `none`. |
| `transform-origin` | Настройка точки поворота и масштабирования через USS пока не работает. |
| `transition-property` | Имена свойств через запятую, например `opacity, scale`; также `all`, `none`. |
| `transition-duration`, `transition-delay` | Время в `s` или `ms`, списки через запятую: `0.2s`, `100ms, 200ms`. |
| `transition-timing-function` | `ease`, `ease-in`, `ease-out`, `ease-in-out`, `linear`; также сочетания `ease-in-`, `ease-out-`, `ease-in-out-` с `sine`, `cubic`, `circ`, `elastic`, `back`, `bounce`. Произвольный `cubic-bezier(...)` не разбирается. |
| `transition` | Например, `opacity 0.2s ease-out 0s`; несколько переходов через запятую. |
| `cursor` | `arrow`, `hand`, `text`, `move`, `resize-horizontal`, `resize-vertical`, `pipette`. |
| `picking-mode` | `ignore` пропускает сам элемент при выборе цели мыши, другое значение устанавливает `Position`; используйте `position` явно. Не является управлением видимостью курсора. |

Переход задаёт изменение поддерживаемого движком анимируемого свойства при смене значения; он сам не запускает бесконечную анимацию. Для управления окном и курсором используйте `UI:OpenWindow` / `UI:CloseWindow`, как в [коротком уроке](./1.QuickStart.md).

Для переключения визуального состояния удобно назначать класс из Lua:

```css
.panel { opacity: 1; }
.panel.dimmed { opacity: 0.4; }
```

```lua
root:EnableInClassList("dimmed", true)
root:EnableInClassList("dimmed", false)
```

Это фрагмент для уже созданного `root`. Методы управления классами запрашивают повторное применение стилей. Прямые присваивания вроде `root.style.opacity = 0.4` используют отдельный Lua API; список свойств `ElementStyle` не совпадает со списком USS.

## Что не поддерживается

Неподдерживаемые свойства игнорируются, а сообщение о них можно найти в консоли. В частности, не поддерживаются `all`, `gap`, `row-gap`, `column-gap`, `grid-template-columns`, `z-index`, `box-shadow`, `visibility`, `transform`, `animation`, сокращения `border` и `background`.

Используйте отступы вместо `gap`, отдельные свойства рамок вместо `border`, `rotate` / `scale` / `translate` вместо `transform`. Для скрытия с исключением из раскладки используйте `display: none`.
