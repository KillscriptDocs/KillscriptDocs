# Создание кастомного сервера
Кастомный сервер можно создать в несколько кликов из главного меню игры. После создания в Esc-меню можно скопировать код приглашения, по которому ваши друзья могут присоединиться. 

# Команды для управления кастомным сервером
Создателю кастомного сервера доступен набор команд для управления сервером. Команды вводятся в консоли, которая открывается кнопкой `~`.

1. `start` Запускает матч из разминки.
2. `restart` Перезагружает карту. Сбрасывает статистику и экономику, переводит в режим разминки.
3. `load-map <map_name>` Переключает сервер на карту по техническому названию карты. Список доступен через `map-list`. 
4. `map-list` Выводит список доступных карт. В него включены в том числе отладочные карты и карты в процессе разработки.
5. `reload` Перезагружает конфигурацию сервера из Google-таблицы, ссылка на которую была указана при создании сервера.
6. `kill-team <team_id>` Убивает всех агентов в команде по номеру команды (1 или 2).

Также создателю кастомного сервера доступен набор команд для управления игроками и агентами. Игроки - это подключенные к серверу пользователи. Агенты - это сущности в игровом мире, за которых могут заходить игроки.
1. `list-agents` Выводит список id агентов с именами для других команд, работающих с id агентов.
2. `kill [agent_id]` Убивает агента по опциональному аргументу id, либо своего агента, если аргумент не передан. Пример: `kill 3`
3. `heal [agent_id]` Лечит агента по опциональному аргументу id, либо своего агента, если аргумент не передан. Пример: `heal 3`
4. `list-players` Выводит id подключенных игроков с их именами для других команд, работающих с id игроков.
5. `kick <player_id>` Отключает игрока от сервера.

Некоторые команды доступны всем игрокам на кастомном сервере.
1. `spectate` Переключает между участием в матче и режимом зрителя.
2. `change-team` Переводит в противоположную команду.
3. `change-agent <number>` Пересаживает игрока в свободного агента в его команде, по номеру от 1 до 5.

# Изменение конфигурации сервера
Большинство параметров игры может быть изменено при помощи кастомной конфигурации сервера. В частности:
1. Баланс оружия и других предметов
2. Глобальные константы, такие как скорость передвижения или длина этапов раунда
3. Флаги, переключающие режим работы механик игры. Например, можно разрешить Wallhack или Air strafe

Чтобы это сделать, нужно скопировать [Google-таблицу с конфигурацией игры](https://docs.google.com/spreadsheets/d/1QH6T_4mY36d7DIXa6bkYwsSAkzthw3pqnn7ogqMLuC0/edit?usp=sharing).

![](../../../images/copy_spreadsheet.png)

После этого нужно сделать таблицу доступной по ссылке.

![](../../../images/share_spreadsheet.png)

![](../../../images/share_spreadsheet_2.png)

Теперь можно свободно редактировать конфигурацию игры. 
Описание параметров можно найти в [Lua-документации](../../../api/GameConfig.md). Ссылку на эту таблицу можно вставить при создании кастомного сервера.
